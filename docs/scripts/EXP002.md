# EXP002 - IF chain power sweep and compression

Final script: `code/EXP002_IFChain_BGUx2_PowerSweep_Compression_v3_LongBaseline.m`
Offline replay: `sim/replay_exp002_compression.m`

## What it measures
Gain and compression of the IF board (Pluto -> BGU1 -> 3 dB pad -> BGU2) at 5 GHz, driven by a 5G NR DL FRC waveform (20 MHz, 30 kHz SCS, 256QAM, scaled to 0.8 of peak, PAPR about 11 dB). The output is measured with the STM32 + LTC5596 detector behind a temporary 6 dB protection attenuator.

## Hardware and manual setup
- Pluto TX, IF board, 6 dB pad before the detector, STM32 on `COM12` (209700 baud).
- The 6 dB pad is not in the real chain: `IFChainOutputCorrected_dBm = Power_meter_dBm + 6`.
- Safety stop: the sweep aborts if the detector (before the +6 dB) reaches 2 dBm.
- The script has a hard-coded `addpath` to another user's MATLAB examples folder (`C:\Users\jpfer\...`); change it on a new machine.

## Flow
1. Build the waveform and compute its PAPR.
2. Plan: sweep Pluto `TxGain` from -44 to -6 dB in 0.5 dB steps. `PlutoOutBaseline_dBm` comes from interpolating `baseline/Baseline_Power_Tx_Pluto.csv` (`TxGain_dB`, `Potencia_SA_dBm`, spectrum-analyzer measurements). If the CSV is missing it falls back to a line, slope 0.9935 and intercept -8.19.
3. For each point: set gain, transmit repeatedly, wait 0.5 s, send `MEAS,<txGain>,50` to the STM32 and read about 50 samples (power, voltage, ADC). Between points the Pluto is set back to -80 dB.
4. Per-point mean/std/min/max, then `IFChainGain = IFOut_corrected - PlutoOut`.
5. Compression: the small-signal gain reference is the mean gain of the first 10 reliable points. Reliable means meter power above -32 dBm and detector voltage above 0.15 V. The reference window is limited to meter power below -24 dBm. `GainCompression = G0 - Gain`.
6. For points below the detector floor, the IF board output baseline is extrapolated as `PlutoOut + G0` (`small_signal_extrapolation_due_to_detector_floor`). For the rest it is the measured value.

## Files
- Reads: `baseline/Baseline_Power_Tx_Pluto.csv`.
- Writes to `data/EXP002_IFCHAIN_BGU1_3dB_BGU2_POWER_SWEEP_COMPRESSION_v3_LongBaseline/<runTag>/`: `raw/*_stm32-power-raw.csv`, `processed/*_power-summary.csv`, `*_gain-compression.csv`, `*_baseline-for-exp003.csv`, `*_results.mat`, and 3 figures.
- The `*_baseline-for-exp003.csv` is the file that is copied to `baseline/Baseline_Power_IF_Board.csv` for EXP003 (manual step).

## Observations about the 2026-10-16 run (raw CSV in `baseline/`)
- 51 points, TxGain -31 to -6 dB, 49-50 samples per point. The script default is -44 to -6 and the older `Baseline_Power_IF_Board.csv` has 77 points, so `TxGain_start_dB` was changed for this run.
- Meter power goes from -36.9 dBm to -13.3 dBm; detector voltage from 0.028 V to 0.709 V.
- The first points (below -32 dBm or 0.15 V) are under the detector guard and are not used for gain.
